🛡️ NEMESIS-X DEPLOYMENT GUIDE 🛡️
🚀 Official Instruction by ERTK Team TzyVXC 🚀
📑 PRE-INSTALLATION
Sebelum memulai, pastikan sistem Debian Anda sudah dalam keadaan up-to-date.

Note: Gunakan user dengan akses sudo.

Bash
# Update repository
sudo apt update && sudo apt upgrade -y

# Install Core Engine
sudo apt install python3 git -y
📂 CLONING THE SYSTEM
Ambil data terenkripsi langsung dari markas besar GitHub Tzy-alt.

Bash
# Clone Repository
git clone https://github.com/Tzy-alt/Port-Scannerr

# Enter the Command Center
cd Port-Scannerr
⚙️ CONFIGURATION LAYER
Karena file dalam repo masih dalam format mentah (.txt), kita harus mengaktifkannya ke format eksekusi Python.

Bash
# Rename the module
mv Port-Scanner.txt main.py

# Set Permission (Optional)
chmod +x main.py
⚡ SYSTEM EXECUTION
Jalankan protokol scanning NEMESIS-X sekarang.

Bash
python3 main.py
